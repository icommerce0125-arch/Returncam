Alur Scan Resi Start & Stop Video

1. Scan Pertama (START): Arahkan scanner ke resi barcode pertama kali. Video rekam secara otomatis dimulai (REC ACTIVE) dan nomor resi terkunci.
2. Perekaman Unboxing / Cek Barang: Tunjukkan proses cek barang return di hadapan kamera.
3. Scan Kedua (STOP & AUTO-SAVE): Scan kembali resi barcode tersebut (atau klik Stop). Video rekam dihentikan secara otomatis dan mengunduh berkas dengan nama format:
YYYY-MM-DD - [Nama Brand] - [No Resi].webm
4. Auto-Stop Pergerakan (Fallback): Jika barang diletakkan & tidak ada gerakan di kamera selama 3 detik, sistem juga akan menghentikan rekaman dan menyimpan file secara otomatis.
